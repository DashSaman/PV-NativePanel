# PV NativePanel

پروژهٔ مستقل برای راه‌اندازی و مدیریت **NaiveProxy** روی سرور خارج، با قابلیت اتصال به پنل مرکزی در آینده.

> وضعیت فعلی: **مرحلهٔ صفر — تحقیق و طراحی معماری**. هنوز نسخهٔ قابل نصب یا Production منتشر نشده است.

## Scope فعلی

- اجرای مستقل روی سرور خارج؛ بدون وابستگی به پنل مرکزی
- حذف کامل سرور، تونل و پهنای‌باند ایران از نسخهٔ فعلی
- اتصال مستقیم کاربران به NaiveProxy
- مدیریت محلی credential، حجم، انقضا، Subscription و مانیتورینگ
- استفاده از NaiveProxy استاندارد؛ بدون Wire Protocol اختصاصی
- نصب آسان در حالت `standalone`
- پیش‌بینی interface تمیز برای اتصال همین پروژه به Controller در نسخه‌های بعد

## ترتیب توسعه

1. ساخت یک Standalone قابل اعتماد
2. حل حسابداری دقیق مصرف هر credential
3. مدیریت محلی کاربران و Subscription
4. نصب، upgrade، backup و diagnostics
5. سپس اضافه‌کردن حالت Controller/Node و پنل مرکزی

معماری آینده نباید پیاده‌سازی نسخهٔ مستقل را پیچیده یا متوقف کند.

## مقیاس آزمون

- هدف نهایی حدود 400 اتصال همزمان
- حداکثر حدود 2TB مصرف روزانه
- آزمایش اولیه روی یک سرور خارجی
- افزایش تدریجی به چند سرور پس از تأیید PoC
