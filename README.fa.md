# PVNaive

<p align="center">
  <img src="web/public/private-network.webp" alt="Private Network" width="120" />
</p>

**PVNaive** پنل مدیریتی حرفه‌ای برای **NaiveProxy** است: یک باینری Go با Caddy forward-proxy داخلی، PostgreSQL 18 و پنل React (Vite + TypeScript) که زیر مسیر `/panel/` سرو می‌شود. مدیریت کاربران، حجم و اعتبار، اشتراک با QR، مانیتورینگ زنده سرور، استخر گره‌ها و نقش‌های مدیریتی — مستندشده و تست‌شده برای انتشار عمومی.

> وضعیت: **فعال روی `https://naive.softarg.ir/panel/`** · تست‌های Go و وب سبز · اسکیمای دیتابیس v33

## امکانات

- **NaiveProxy بومی**: Caddy `forward_proxy` روی پورت 443 با `probe_resistance`، `hide_ip`، `hide_via`؛ اعتبار هر کاربر مستقیم از دیتابیس با Caddy همگام می‌شود.
- **چرخه کامل کاربر**: ساخت، ویرایش، تعلیق/فعال‌سازی، لغو امن، افزودن/تعیین حجم، تمدید، تمدید از پلن، Next Plan، Reset مصرف — همه صریح، auditable و capability-gated.
- **QR دوگانه**: هر کاربر هم **QR لینک ساب** (پروفایل خودکار کلاینت) و هم **QR مستقیم `naive+https://`** (ورود دستی بدون ساب) دارد.
- **صفحه حساب دوزبانه** (`/s/<token>`): مصرف، حجم، انقضا، هر دو QR و راهنمای کامل اتصال به فارسی و انگلیسی.
- **تشخیص خودکار کلاینت**: `/sub/<token>` بر اساس User-Agent خروجی naive خام، sing-box JSON (Karing)، Clash/Mihomo، Hiddify و لیست base64 v2ray می‌دهد؛ با `?family=` هم قابل اجبار است.
- **مانیتورینگ زنده**: استریم SSE (هر ۱ ثانیه) با گیج CPU/RAM/دیسک، نرخ زنده شبکه از اختلاف counter سمت سرور، لود و آپ‌تایم؛ اگر استریم قطع شود نمونه‌برداری دوره‌ای جایگزین می‌شود.
- **استخر گره‌ها**: ثبت گره با توکن، مانیفست امضاشده، نمایش drift و حالت تعمیر (R5 با mTLS).
- **نقش‌ها**: owner / admin / reseller / operator / auditor با جداسازی tenant و اعتبار/ledger نماینده.
- **امنیت**: کوکی `__Host-`، CSRF، MFA-TOTP اختیاری، رمزنگاری AES-GCM اسرار اشتراک، ledgerهای append-only، audit کامل.
- **ظاهر**: تم «Private Gold روی شیشه نیمه‌شب» — گلس‌مورفیزم تیره (Vazirmatn + JetBrains Mono)، پیروی از تم سیستم، RTL-first.

## نصب سریع

```bash
git clone https://github.com/DashSaman/PV-NativePanel.git
cd PV-NativePanel/docker

PVNAIVE_DOMAIN=naive.example.com \
PVNAIVE_PROXY_USER=pvbootstrap \
PVNAIVE_PROXY_PASSWORD='یک-رمز-قوی' \
PVNAIVE_OWNER_EMAIL=admin@example.com \
PVNAIVE_OWNER_PASSWORD='رمز-مالک' \
bash install.sh
```

- پنل: `https://<دامنه>/panel/`
- صفحه حساب کاربر: `https://<دامنه>/s/<token>`
- اشتراک ماشینی: `https://<دامنه>/sub/<token>`
- Caddyfile در `./data/caddy/Caddyfile` ماندگار است؛ فایل‌های asset با هدر `immutable` و `index.html` با `no-cache` سرو می‌شود تا بعد از هر به‌روزرسانی، کاربران نسخه تازه ببینند.
- `PVNAIVE_NAIVE_PUBLIC_HOST` تعیین می‌کند همه لینک‌ها و QRها از کدام دامنه ساخته شوند.

- **کارت‌های آماری** — کل کاربران، کاربران فعال، پلن‌ها، نیازمند توجه؛ هر عدد مستقیم از دیتابیس می‌آید.
- **توزیع سرویس‌ها (دونات)** — فعال / منتظر اتصال / تعلیق / پایان‌یافته با درصد هر بخش (SVG خالص، بدون کتابخانه).
- **۷ و ۳۰ روز آینده** — حساب‌هایی که به‌زودی منقضی می‌شوند.
- **مانیتورینگ زنده سرور**:
  - نشان **«زنده · هر ۱ ثانیه»** — سبز = استریم فعال؛ کهربایی = نمونه‌برداری دوره‌ای (هر ۵ ثانیه) با تلاش خودکار برگشت.

  - **گیج‌ها** — پردازنده / حافظه / دیسک با رنگ آستانه‌ای (سبز < ۷۵٪، کهربایی < ۹۰٪، قرمز ≥ ۹۰٪).

  - **ترافیک شبکه** — نمودار زنده دریافت/ارسال با پنجره ۹۰ نمونه و خط «الان»؛ نرخ‌ها سمت سرور محاسبه می‌شوند.
- **پشتیبانی / خروج امن / مدیریت روزمره** — میان‌برهای پایین داشبورد.

- **کاربر جدید** — نام کاربری، حجمی/نامحدود، حالت اعتبار (**از همین حالا / از اولین اتصال موفق / تاریخ دستی**)، رمز خودکار (فقط یک بار نمایش).

- **منوی ••• هر ردیف**:

  - **نشست‌های فعال** — جلسات زنده با قطع دقیق هر نشست.
  - **لغو حساب** — حذف امن: اعتبار Runtime باطل، تاریخچه حفظ، ثبت در audit.

## اشتراک و تحویل QR

هر کاربر یک توکن اشتراک دارد که سه جا رندر می‌شود:

| مسیر | مخاطب | رفتار |
| --- | --- | --- |
| `/sub/<token>` | کلاینت‌ها | تشخیص خودکار: naive خام، sing-box (Karing)، Clash، Hiddify، base64 v2ray؛ با `?family=` قابل اجبار. |
| `/s/<token>` | انسان‌ها | صفحه حساب فقط‌خواندنی: مصرف، حجم، انقضا، هر دو QR، راهنمای کامل (FA/EN). |
| دیالوگ پنل | مالک | همان داده‌ها با هر دو QR و دکمه کپی — باز کردنش هیچ چیزی را تغییر نمی‌دهد. |

<p align="center"><img src="docs/screenshots/qr-delivery.png" width="75%" alt="QR دوگانه" /></p>

**دو راه مستقل اتصال — هر دو فقط با اسکن:**

1. **QR لینک ساب** — پروفایل کلاینت زنده می‌ماند؛ تغییر حجم/رمز/توکن با Refresh منتقل می‌شود.
2. **QR مستقیم Naive** (`naive+https://user:pass@host:443`) — ورود دستی بدون ساب؛ عالی برای تست سریع.

## اتصال کلاینت‌ها

راهنمای کامل دوزبانه داخل صفحه `/s/` هست. خلاصه:

| کلاینت | پلتفرم | سریع‌ترین روش |
| --- | --- | --- |
| **Karing** (پیشنهادی) | اندروید / iOS / ویندوز / مک | «+» ← اسکن QR ← اسکن QR لینک ساب |
| v2rayNG | اندروید | Subscriptions ← + ← چسباندن لینک ساب |
| NekoBox / NekoRay | اندروید / کامپیوتر | گروه جدید subscription یا ایمپورت `naive+https://` از کلیپ‌بورد |
| Hiddify | اندروید / iOS / کامپیوتر | + ← افزودن از کلیپ‌بورد یا اسکن QR |
| sing-box | کامپیوتر | `/sub/<token>?family=singbox` |
| Clash Meta / Mihomo | کامپیوتر | `/sub/<token>?family=clash` |

نکات رفع اشکال (روی صفحه هم هست): بعد از اتصال موفق وضعیت صفحه **«فعال / آنلاین»** می‌شود؛ بعد از تغییر حجم/رمز ساب را Refresh کن؛ حساب منقضی یا تمام‌شده وصل نمی‌شود؛ در نهایت QR مستقیم Naive را امتحان کن.

## معماری

```
┌────────────────────────── کانتینر pvnaive ─────────────────────────────┐
│  پنل React (/panel)     Go API (:8080)     Caddy (:80/:443)            │
│   ├─ بیلد Vite           ├─ /api/v1/*        ├─ TLS (Let's Encrypt)     │
│   ├─ تم گلس RTL          ├─ استریم SSE       ├─ forward_proxy (naive)   │
│   └─ کدکننده QR محلی     ├─ نقش‌های RBAC     ├─ /sub ، /s ، /panel      │
│                          ├─ accounting        └─ سوکت accounting ◄─────┤
│                          └─ fleet/pool mTLS        شمارش دقیق بایت    │
│  PostgreSQL 18 (اسکیمای v33، مایگریشن‌های فقط-جلو، بکاپ رمزشده)        │
└─────────────────────────────────────────────────────────────────────────┘
```

- **Accounting** فقط-الحاقی است: آپلود/دانلود به تفکیک اعتبار، baseline مقاوم به ری‌استارت، resetهای auditable. اجرای سخت سهمیه فقط بعد از اثبات دقیق بودن شمارش فعال می‌شود؛ تا آن زمان رابط کاربری وضعیت «در دسترس نیست» صادقانه نشان می‌دهد.
- **اعتبار از اولین اتصال** فقط با CONNECT موفق احراز‌هویت‌شده شروع می‌شود — هرگز با باز کردن پنل یا خواندن QR.
- **Steering / cover** (R6، پیش‌فرض خاموش) و **fleet mTLS pull** (R5) سیم‌کشی شده‌اند.

## مدل امنیتی

- نشست‌ها: `__Host-pvnaive_session` + CSRF؛ اتصال به هش User-Agent؛ MFA (TOTP + کد بازیابی).
- اسرار: رمزهای Runtime با AES-GCM رمزنگاری می‌شوند (کلید `runtime-v1`)؛ توکن اشتراک به‌صورت SHA-256 ذخیره می‌شود؛ رمزهای تولیدی فقط یک بار نمایش داده می‌شوند.
- عملیات فقط‌خواندنی (دیدن QR، کپی لینک، جزئیات) با تست قراردادی اثبات شده که هیچ stateی را تغییر نمی‌دهند.
- audit برای همه عملیات چرخه حیات؛ لاگ امنیتی با شناسه درخواست؛ بسته‌های diagnostics.
- صفحه `/s/` خصوصی است: `noindex` + هشدار انتشار عمومی.

## اعتبار طراحی

روش‌شناسی بصری (سطوح گلس، سیستم اکسنت طلایی، جفت‌فونت، جداسازی رنگ نمودارها) از دیتاست متن‌باز **[ui-ux-pro-max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)** — پروفایل‌های Glassmorphism و Modern Dark — و با فارسی‌سازی RTL به کمک Vazirmatn و JetBrains Mono تطبیق داده شده است.
