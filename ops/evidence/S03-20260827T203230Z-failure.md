## Root cause

The failure is caused by the APT candidate parser in `scripts/stages/S03-database.sh`:

```bash
candidate="$(apt-cache policy "${package_name}" | awk '/Candidate:/ {print $2; exit}')"
```

The stage runs with `set -o pipefail`. The early `exit` in `awk` can close the pipe while `apt-cache policy` is still writing. `apt-cache` then receives SIGPIPE and exits 141, which `pipefail` promotes to a stage failure even though the Candidate value itself is valid.

This is a stage-code bug, not an APT repository failure and not a target-host failure.
