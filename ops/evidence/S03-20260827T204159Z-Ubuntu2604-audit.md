## Problems found

1. The original APT Candidate parser used an early-exit `awk` under `set -o pipefail`, producing exit 141/SIGPIPE.
2. The S03 package list requested the obsolete/non-installable `postgresql-contrib` meta package on Ubuntu 26.04.
3. The stage did not explicitly lock the expected PostgreSQL major or verify `pgcrypto` extension files before DB mutation.
4. The stage did not run an APT dependency simulation before install.
5. DNS and `SHOW listen_addresses` checks used avoidable pipelines that were hardened to reduce pipefail/SIGPIPE exposure.
6. DB backup used `--no-owner --no-acl`, so a restore could succeed structurally while losing `pvnaive_owner` ownership and `pvnaive_app` GRANT/REVOKE boundaries.
7. Restore drill did not verify ownership, ACLs, pgcrypto presence, or preservation of the RLS signing key.
